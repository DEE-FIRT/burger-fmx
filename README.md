# 🍔 Burger FMX — Landing Page Gastronómica & Multi-idioma

> **Live Demo:** [https://dee-firt.github.io/burger-fmx/index.html](https://dee-firt.github.io/burger-fmx/index.html)

**Burger FMX** es una Landing Page moderna e interactiva desarrollada para una marca de hamburguesas artesanales (*smash burgers*), con estética urbana y soporte multi-idioma (Español e Inglés).

---

## 🚀 Características
* 🌐 **Bilingüe:** Toggle dinámico entre Español e Inglés.
* 📱 **100% Responsivo:** Adaptado para celulares y computadoras.
* 🎨 **Estética Urbana:** Fuentes de Google Fonts y efectos neón.

---

## 🛠️ Tecnologías
* HTML5 Semantic
* CSS3 (Flexbox & Grid, Animaciones)
* GitHub Pages
