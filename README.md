# 🍔 Burger FMX — Landing Page Gastronómica & Multi-idioma

![Burger FMX Banner](images/2-de-libra.png)

> **Live Demo:** [https://dee-firt.github.io/burger-fmx/index.html](https://dee-firt.github.io/burger-fmx/index.html)

**Burger FMX** es una *Landing Page* moderna, interactiva y de alto impacto visual desarrollada para una marca de hamburguesas artesanales (*smash burgers*). El proyecto fue diseñado con un enfoque *mobile-first*, estética urbana con efectos neón y soporte multi-idioma nativo (Español e Inglés).

---

## 🚀 Características Principales

* 🌐 **Soporte Bilingüe (EN / ES):** Toggle dinámico para alternar entre la versión en español e inglés.
* 📱 **Diseño 100% Responsivo:** Adaptado para celulares, tablets y computadoras de escritorio.
* 🎨 **Estética Urbana & Neón:** Uso estratégico de fuentes tipográficas impactantes (`Bebas Neue`, `Poppins`, `Montserrat`), sombras brillantes y contraste oscuro.
* 🍔 **Sección de Menú Interactivo:** Tarjetas de productos destacados con imágenes optimizadas y botones de llamada a la acción (*CTA*).
* ⚡ **Navegación Fluida:** Menú hamburguesa animado exclusivamente con CSS y desplazamiento suave (*Smooth Scroll*).
* 📩 **Sección de Contacto & Footer:** Accesos rápidos a ubicaciones, redes sociales y horarios de atención.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semantic:** Estructura limpia y accesible.
* **CSS3 Custom Properties:** Variables CSS para mantener coherencia en colores, efectos de neón y fuentes.
* **CSS Flexbox & Grid:** Layouts modernos y adaptables.
* **Google Fonts:** `Bebas Neue`, `Poppins`, `Montserrat`, `Playfair Display`.
* **GitHub Pages:** Despliegue y hosting en vivo.
